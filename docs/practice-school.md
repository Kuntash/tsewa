# Retired practice environment

The temporary Tsewa Practice School organization was used to validate admissions,
profile editing, family relationships, school setup, and enrollment changes. It has
now been removed from the application and must not appear in organization selectors,
reports, or operational instructions.

Future write-workflow testing should use a purpose-built non-production environment
or a THF-approved test record. Do not create another production organization solely
for development testing.
