# Product language

Tsewa is used by school and care staff, including people who use English as a
second language. Daily screens should use short, familiar words.

## Rules

- Name the task: **People**, **Students**, **Schools**, **Classes**, **Documents**.
- Prefer one short sentence over a technical explanation.
- Use **View only** when editing is unavailable.
- Use **Not recorded** when a value is missing.
- Show a warning only when the user can understand or act on it.
- Keep database, import, source ID, reconciliation, and migration terms out of
  daily screens.
- Put technical import details in a restricted administration page when one is
  needed.
- Do not show a status column when every row has the same value.
- Highlight exceptional statuses such as **Transferred** or **Withdrawn** only
  after those workflows exist.

## Preferred words

| Avoid                | Use                          |
| -------------------- | ---------------------------- |
| People Registry      | People                       |
| Operational console  | Home or Dashboard            |
| Student allocation   | Student                      |
| Class roster         | Class                        |
| Longitudinal record  | Full history                 |
| Registry status      | Status                       |
| Migration provenance | Import details               |
| Source-authoritative | Remove from user-facing copy |
| Legacy recorded      | Remove from daily screens    |
| Reconciled record    | Record                       |

Internal table and API names may remain technical. This guide applies to text
shown to users.
